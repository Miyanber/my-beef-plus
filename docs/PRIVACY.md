# プライバシーポリシー (Privacy Policy)

**最終更新日**: 2026年11月17日  
**適用対象**: ブラウザ拡張機能「My BEEF+」(`my-beef-plus`)

「My BEEF+」（以下、「本拡張機能」）は、神戸大学の学修管理システム（BEEF+）の利便性を向上させる目的で開発された非公式オープンソースブラウザ拡張機能です。本拡張機能では、ユーザーのプライバシー保護を最優先とし、個人情報および学内データを尊重します。

---

## 1. 取得する情報とその利用目的

本拡張機能は、ユーザーの個人を特定できる情報を外部に収集・保存・送信することは一切ありません。

| データの種類 | 取り扱い方法 | 利用目的 |
| :--- | :--- | :--- |
| **認証情報（ID・パスワード・Cookie）** | **一切取得・保持・送信しません** | なし（ブラウザネイティブのログイン済みセッションを直接利用） |
| **時間割・講義・課題データ** | **端末ローカルのみに保存** (`chrome.storage.local` / `localStorage`) | 画面表示およびページ遷移時の高速描画（SWR キャッシュ） |
| **BEEF2026 連携 URL・同期設定** | **端末ローカルのみに保存** (`chrome.storage.local` / `localStorage`) | 科目カードからの BEEF2026 直リンク、およびオプトイン時の BEEF2026 課題締切同期 |
| **ユーザー表示名・通知一覧** | **端末内でのみ参照・キャッシュ** | ヘッダーのユーザーアバター・お知らせ/メッセージメニュー表示 |
| **UI 設定（テーマ・サイドバー状態）** | **端末ローカルのみに保存** | ライト/ダークテーマ同期およびサイドバー開閉状態の保持 |
| **アナリティクス・トラッキング** | **一切導入していません** | なし（Google Analytics 等の外部計測 SDK は不使用） |

---

## 2. 外部通信および第三者提供

本拡張機能は、**開発者を含むいかなる外部サーバーへのデータ送信も行いません**。

- 拡張機能内で実行されるデータ取得・画面操作の対象は、神戸大学公式の以下のシステムに限られます。
  - **BEEF+** (`https://beefplus.center.kobe-u.ac.jp/*`): ページ遷移時の HTML 取得、お知らせ詳細取得、および講義資料の 1 クリックダウンロード一時 API 連携
  - **BEEF2026** (`https://beef.center.kobe-u.ac.jp/my*`): ユーザーが課題一覧画面で「BEEF2026 同期」を有効（ON）にしている場合のみ、ダッシュボードのタイムライン DOM から課題締切情報を読み取りローカルへ保存
- 取得したデータが第三者に提供、共有、販売されることは決してありません。

> [!NOTE]
> 独自 React UI 内の欧文フォント表示のため、スタイルシート上で Google Fonts (`fonts.googleapis.com`) を参照していますが、拡張機能からユーザー固有のパラメータや個人データを送信することはありません。

## 3. 使用するブラウザ権限 (Permissions)

本拡張機能が要求・利用する権限およびその正当な理由は以下の通りです。

- **`storage` (`chrome.storage.local` および同一オリジンの `localStorage`)**:  
  時間割・講義詳細・課題一覧の高速描画キャッシュ、UI 設定（テーマ・サイドバー状態）、および BEEF2026 連携設定・課題キャッシュを端末ローカルに保存する目的にのみ使用します。
- **対象ホストへのアクセス (`https://beefplus.center.kobe-u.ac.jp/*`, `https://beef.center.kobe-u.ac.jp/my*`)**:  
  - `beefplus.center.kobe-u.ac.jp`: モダン UI の描画、テーマ注入、および教材の 1 クリックダウンロード API 連携を行うために使用します。
  - `beef.center.kobe-u.ac.jp/my*`: ユーザーが「BEEF2026 同期」を有効化している場合に、ダッシュボードの未提出課題・テストの締切情報を読み取るために使用します。
  - これら以外の Web サイトへのアクセス権限は要求しません。
- **タブ制御 (`chrome.tabs` API — バックグラウンド同期時のみ)**:  
  課題一覧画面で「BEEF2026 同期」が有効な場合のみ、`https://beef.center.kobe-u.ac.jp/my/` を非アクティブなタブとして一時的に開き、タイムライン取得完了後（またはタイムアウト後）に自動で閉じます。他のタブの内容や閲覧履歴を読み取ることはありません。

---

## 4. データの削除方法

本拡張機能がローカルに保存したデータ（キャッシュおよび各種設定）は、以下の方法で消去できます。

1. 拡張機能のアイコン右クリックまたは `chrome://extensions/` から「My BEEF+ を削除」を実行する（`chrome.storage.local` のデータが消去されます）。
2. ブラウザの設定からサイトデータ（`beefplus.center.kobe-u.ac.jp` / `beef.center.kobe-u.ac.jp` の「Cookie と他のサイトデータ」 / `localStorage`）を消去する。
