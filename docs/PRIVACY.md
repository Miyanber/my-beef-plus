# プライバシーポリシー (Privacy Policy)

**最終更新日**: 2026年11月11日  
**適用対象**: ブラウザ拡張機能「My BEEF+」(`my-beef-plus`)

「My BEEF+」（以下、「本拡張機能」）は、神戸大学の学修管理システム（BEEF+）の利便性を向上させる目的で開発された非公式オープンソースブラウザ拡張機能です。本拡張機能では、ユーザーのプライバシー保護を最優先とし、個人情報および学内データを尊重します。

---

## 1. 取得する情報とその利用目的

本拡張機能は、ユーザーの個人を特定できる情報を外部に収集・保存・送信することは一切ありません。

| データの種類 | 取り扱い方法 | 利用目的 |
| :--- | :--- | :--- |
| **認証情報（ID・パスワード・Cookie）** | **一切取得・保持・送信しません** | なし（ブラウザネイティブのセッションを直接利用） |
| **時間割・講義・課題データ** | **端末ローカルのみに保存** (`chrome.storage.local`) | 画面表示およびページ遷移時の高速描画（キャッシュ） |
| **ユーザー表示名・学籍番号** | **端末内でのみ一時参照** | ヘッダーのユーザーアバター表示のみ |
| **アナリティクス・トラッキング** | **一切導入していません** | なし（Google Analytics等の外部SDKは不使用） |

---

## 2. 外部通信および第三者提供

本拡張機能は、**開発者を含むいかなる外部サーバーへの通信も行いません**。

- 拡張機能内で実行されるネットワーク通信は、神戸大学公式の BEEF+ サーバー（`https://beefplus.center.kobe-u.ac.jp/*`）との間で、ページ遷移時のデータ取得および講義資料ダウンロードの一時API連携を行うものに限られます。
- 取得したデータが第三者に提供、共有、販売されることは決してありません。

---

## 3. 使用するブラウザ権限 (Permissions)

本拡張機能が要求する権限およびその正当な理由は以下の通りです。

- **`storage`**:  
  時間割や課題一覧の表示を高速化するため、パースしたデータをブラウザのローカル領域に一時キャッシュする目的にのみ使用します。
- **`host_permissions` (`https://beefplus.center.kobe-u.ac.jp/*`)**:  
  BEEF+ の画面上でモダンなUIを表示し、教材の1クリックダウンロードAPIを呼び出す目的にのみ使用します。他のいかなるWebサイトへのアクセス権限も要求しません。

---

## 4. データの削除方法

本拡張機能がローカルに保存したデータ（キャッシュ）は、以下のいずれかの方法で即座に完全に消去されます。

1. 拡張機能のアイコン右クリックまたは管理画面から「My BEEF+ を削除」を実行する。
2. ブラウザの設定から「閲覧履歴データの消去」（Cookieと他のサイトデータ）を実行する。

---

## 5. プライバシーポリシーの改定

本ポリシーは、法令の変更や本拡張機能の機能追加等に伴い、予告なく改定されることがあります。重要な改定がある場合は、本リポジトリおよびストア掲載ページにて告知します。
